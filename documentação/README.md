# Documentação funcional (desenvolvedores)

Esta pasta reúne documentação técnica detalhada para apoiar:
- entendimento do funcionamento das telas;
- onboard de novos desenvolvedores;
- investigação de bugs e inconsistências de regra;
- revisão de possíveis más implementações.

## Conteúdo inicial
- `dashboard.md`: arquitetura, fontes de dados, cálculos e critérios do Dashboard executivo.
- `dashboard-tv.md`: funcionamento do Dashboard TV, widgets, metas, atualização e pontos críticos de auditoria.
